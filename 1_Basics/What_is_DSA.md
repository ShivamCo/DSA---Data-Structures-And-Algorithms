# Data Structures and Algorithms (DSA)

## Introduction

Data Structures and Algorithms (DSA) are fundamental concepts in computer science used to organize, manage, and process data efficiently.

- **Data Structures** are ways of storing and organizing data.
- **Algorithms** are step-by-step procedures used to solve problems or perform operations on data.

Together, they help developers write efficient and optimized programs.

---

# Data Structures

A **Data Structure** is a method of organizing data so it can be accessed and modified efficiently.

## Types of Data Structures

There are two main types of data structures:

### 1. Linear Data Structures

In linear data structures, elements are arranged sequentially.

#### Arrays

A collection of elements stored in contiguous memory locations.

**Features:**

- Constant-time access using index: `O(1)`
- Fixed size
- Fast data retrieval

#### Linked Lists

A sequence of nodes where each node contains:

- Data
- Reference (pointer) to the next node

**Features:**

- Dynamic size
- Efficient insertion and deletion
- Non-contiguous memory allocation

#### Stacks

A data structure that follows the **LIFO (Last In, First Out)** principle.

**Operations:**

- `Push` → Add an element
- `Pop` → Remove an element

**Example:**  
A stack of plates.

#### Queues

A data structure that follows the **FIFO (First In, First Out)** principle.

**Operations:**

- `Enqueue` → Add an element
- `Dequeue` → Remove an element

**Example:**  
People standing in a queue.

---

### 2. Non-Linear Data Structures

In non-linear data structures, elements are not arranged sequentially.

#### Trees

A hierarchical data structure consisting of nodes connected by edges.

**Common Uses:**

- File systems
- Databases
- Hierarchical data representation

#### Graphs

A collection of nodes (**vertices**) connected by **edges**.

**Common Uses:**

- Social networks
- Navigation systems
- Computer networks

# Algorithms

An **Algorithm** is a step-by-step process used to solve a problem or perform a task.

## Characteristics of a Good Algorithm

- Efficient
- Easy to understand
- Optimized for time and memory usage

## Examples of Algorithms

- Searching Algorithms
- Sorting Algorithms
- Pathfinding Algorithms
